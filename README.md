# Onasis Links Management Dashboard

> Internal dashboard for managing products, quotes, and users for Onasis Links Resources Limited.

## 🚀 Tech Stack

- React + Vite
- Tailwind CSS
- React Router v6
- Zustand (State Management)
- Axios (API Client)
- React Hook Form + Zod
- Lucide React (Icons)
- Recharts (Charts)
- Framer Motion (Animations)

## 📁 Project Structure
src/
├── api/ # API calls and axios config
├── components/ # Reusable components
├── context/ # React Context providers
├── hooks/ # Custom React hooks
├── pages/ # Page components
├── stores/ # Zustand stores
├── utils/ # Utility functions
└── constants/ # App constants
